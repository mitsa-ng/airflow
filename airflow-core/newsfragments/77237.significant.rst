The rendered-fields cleanup that runs after every task execution no longer scans a task's whole attempt history. ``rtif_v2`` now stores the owning attempt's ``dag_id``, ``task_id`` and ``run_id`` (backfilled by migration and indexed), and the cleanup deletes by those columns instead of probing ``task_instance`` once per attempt. On PostgreSQL the delete previously read a page per attempt (~12,600 buffers for a task with ~3,200 attempts) on every task run; its cost now depends only on the retained rows.
